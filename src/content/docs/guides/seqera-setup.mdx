## Base Terraform

The basic configuration of Terraform for our setup will require two providers. One
provider (AWS) will be brought in automatically due to the use of the "s3" backend.

The other provider is the one that drives the Seqera API.

Our first problem is that we need to safely give Terraform permissions in our Seqera account
to use the API – through the use of a bearer token. There are numerous approaches to
secret management in Terraform – in our case here we will use a Terraform variable.

## Base AWS Setup

In our AWS environment - we need to split the terraforming of IAM users from other
activity - as our organisation has policies limiting the creation of IAM users to
a single administrator. In an organisation without this requirement - there would
be no need for the split. However, given this is how we have done it - we will
document it this way as it is relatively easy to just join the two sections.

```terraform
locals {
  # this is set at the enterprise setup level and "TowerForge-" is the default.
  # if we changed this, this flows through into some of the policies below
  tower_forge_prefix = "TowerForge-"
}

# an IAM user which will be used by Seqera to then create Batch environments
resource "aws_iam_user" "batch_forge_user" {
  name = "seqera-batch-forge-user"
}

# an IAM group we will put the user in - this is recommended AWS technique (see IAM.2 security control)
resource "aws_iam_group" "batch_forge_group" {
  name = "seqera-batch-forge-group"
}

resource "aws_iam_user_group_membership" "batch_forge_user_in_group" {
  user = aws_iam_user.batch_forge_user.name

  groups = [
    aws_iam_group.batch_forge_group.name
  ]
}

resource "aws_iam_group_policy_attachment" "attach_policies_to_group" {
  group      = aws_iam_group.batch_forge_group.name
  policy_arn = aws_iam_policy.batch_forge_policy.arn
}

resource "aws_iam_policy" "batch_forge_policy" {
  # NOTE: these can't be inline policies as they are > 2048 characters
  name_prefix = "seqera-iam-policy"
  description = "Policy giving permissions to Seqera for compute environments and UI"

  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Sid    = "BatchEnvironmentManagementCanBeRestricted"
        Effect = "Allow"
        Action = [
          "batch:CreateComputeEnvironment",
          "batch:CreateJobQueue",
          "batch:DeleteComputeEnvironment",
          "batch:DeleteJobQueue",
          "batch:UpdateComputeEnvironment",
          "batch:UpdateJobQueue",
        ]
        Resource = [
          "arn:aws:batch:*:*:compute-environment/${local.tower_forge_prefix}*",
          "arn:aws:batch:*:*:job-queue/${local.tower_forge_prefix}*",
        ]
      }
      # standard policies as recommended by Seqera documentation
      # https://docs.seqera.io/platform-enterprise/compute-envs/aws-batch
      # ....
      # .... in the interests of brevity we have omitted them here
      # ....
    ]
  })
}
```
