## Purpose

This section describes the solution architecture of a GUARDIANS **genomic data node** (GDN):
the system that sits between Information Asset Owners and the researcher environments that need to
use their data.

Its structure is (very) loosely based on
[arc42](https://arc42.org/overview) with diagrams
following the [C4 model](https://c4model.com).

**NOTE the rendered architecture diagrams can be quite small - click on them
to view a zoomed version.**
