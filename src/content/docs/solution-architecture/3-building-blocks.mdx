This page describes each container in a genomic data node: what it is responsible for,
what it is built with and how other parts talk to it. The diagram is the same view as on
the [System Context](../2-system-context) page.

## Summary

| Service        | Responsibility                                    | Technology                                      | Status      | Details                                                                |
|------------------|---------------------------------------------------|-------------------------------------------------|-------------|------------------------------------------------------------------------|
| Data Releaser           | Control plane for other services         | `data-releaser` (Go application)          | Production  | [data-releaser](../../technology/data-releaser) |
| Data Copy        | Moving datasets into, and out of, the node        | `steps-s3-copy` (AWS Step Function), `copyrite` (Rust)           | Production  | [steps-s3-copy](../../technology/steps-s3-copy), [copyrite](../../technology/copyrite) |
| htsget           | Serving authorised slices of genomic data         | `htsget-rs` on AWS Lambda, VPC Lattice          | Production  | [htsget-rs](../../technology/htsget-rs), [AWS-native sharing](../../guides/aws-native-data-sharing) |

## Data Copy

**Responsibility.** Long-running, resumable copying of large sets of objects between
object stores, with checksums verified end to end. It is used both to bring Information Asset Owner data
*into* the node and to *release* data to collaborators.

**Interfaces.**

| Direction | Counterpart        | Protocol          | Purpose                                         |
|-----------|--------------------|-------------------|-------------------------------------------------|
| Inbound   | Operator / Information Asset Owner | AWS API (Step Functions `StartExecution`) | Start a copy with a list of objects and a destination |
| Outbound  | Long Term Data Storage  | S3 API            | Read source objects, trigger Glacier thaws      |
| Outbound  | Dataset Storage    | S3 API            | Write objects and `.sums` checksum files        |

**Notes.** Meets the [Data Copying requirements](../../requirements/data-copying), including
thawing from cold storage (`DCREQ‑6`), idempotent re-runs (`DCREQ‑13`) and cost reports
([steps-s3-copy costing](../../technology/steps-s3-copy-costing)).

## Dataset Storage

**Responsibility.** Durable storage of datasets in the agreed [dataset format](../dataset-formatting),
and the "data block server" for htsget: the byte ranges in htsget tickets are pre-signed
URLs into this storage.

**Interfaces.**

| Direction | Counterpart            | Protocol                | Purpose                                     |
|-----------|------------------------|-------------------------|---------------------------------------------|
| Inbound   | Data Copy              | S3 API                  | Write datasets                              |
| Inbound   | htsget                 | S3 API                  | Read indexes, sign URLs                     |
| Inbound   | Researcher Environment | HTTPS (pre-signed URLs) | Fetch byte ranges; restricted to designated VPCs by bucket policy |

## htsget

**Responsibility.** Implements the [GA4GH htsget protocol](https://samtools.github.io/hts-specs/htsget.html)
for reads (BAM/CRAM) and variants (VCF/BCF). It maps meaningful sample identifiers onto
storage locations, authorises each request, and returns tickets of pre-signed URLs covering
only the byte ranges required.

**Interfaces.**

| Direction | Counterpart            | Protocol                     | Purpose                                 |
|-----------|------------------------|------------------------------|-----------------------------------------|
| Inbound   | Researcher Environment | HTTPS via VPC Lattice        | htsget ticket requests                  |
| Outbound  | REMS                   | HTTPS                        | Check entitlements                      |
| Outbound  | Dataset Storage        | S3 API                       | Read indexes; pre-sign URLs with the node's own IAM principal |
