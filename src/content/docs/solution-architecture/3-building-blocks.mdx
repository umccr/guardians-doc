This page describes each container in a genomic data node: what it is responsible for
and how it interfaces with other components.

## Summary

| Service        | Responsibility                                    | Technology                                      | Status      | Details                                                                |
|------------------|---------------------------------------------------|-------------------------------------------------|-------------|------------------------------------------------------------------------|
| Data Releaser           | Control plane for other services         | `data-releaser` (Go application)          | Release Candidate  | [data-releaser](../../technology/data-releaser) |
| Data Copy        | Moving datasets into, and out of, the node        | `steps-s3-copy` (AWS Step Function), `copyrite` (Rust)           | Production  | [steps-s3-copy](../../technology/steps-s3-copy), [copyrite](../../technology/copyrite) |
| Data Cache       | Temporary dataset storage and htsget data blocks | Amazon S3 | — | [Data Cache](#data-cache) |
| htsget           | Serving authorised slices of genomic data         | `htsget-rs` (Rust) on AWS Lambda, VPC Lattice          | Production  | [htsget-rs](../../technology/htsget-rs), [AWS-native sharing](../../guides/aws-native-data-sharing) |
| Bill and Log Processor           | Providers bill and log data for operator analysis         | `curtrail` (Python CLI and library)         | Production  | [curtrail](../../technology/curtrail) |

## Data Releaser

**Responsibility.** Stores records of data share activity and controls policies and other configurations that enable
the data sharing activities to actually happen.

**Interfaces.**

| Direction | Counterpart        | Protocol          | Purpose                                         |
|-----------|--------------------|-------------------|-------------------------------------------------|
| Inbound   | Operator | None (CLI) | Issues commands via CLI |
| Outbound  | Data Copy    | AWS API            | Start a copy with a list of objects and a destination        |
| Outbound  | Data Cache    | AWS API            | Alters cache bucket policies to support sharing        |
| Outbound  | htsget  | S3 API            | Writes configuration objects consumed by htsget      |

## Data Copy

**Responsibility.** Long-running, resumable copying of large sets of objects between
object stores, with checksums verified end to end. It is used to bring Information Asset Owner data
*into* the node.

**Interfaces.**

| Direction | Counterpart        | Protocol          | Purpose                                         |
|-----------|--------------------|-------------------|-------------------------------------------------|
| Inbound   | Data Releaser  | AWS API | Start a copy with a list of objects and a destination |
| Outbound  | Long Term Data Storage  | S3 API            | Read source objects, trigger Glacier thaws      |
| Outbound  | Data Cache    | S3 API            | Write objects        |

## Data Cache

**Responsibility.** Temporary storage of datasets in the agreed format and the "data block server" for htsget.

**Interfaces.**

| Direction | Counterpart            | Protocol                | Purpose                                     |
|-----------|------------------------|-------------------------|---------------------------------------------|
| Inbound   | Data Copy              | S3 API                  | Write datasets                              |
| Inbound   | htsget                 | S3 API                  | Read indexes, sign URLs                     |
| Inbound   | Researcher Environment | HTTPS (pre-signed URLs) | Fetch byte ranges; restricted to designated VPCs by bucket policy |

## htsget

**Responsibility.** Implements the [GA4GH htsget protocol](https://samtools.github.io/hts-specs/htsget.html)
for reads (BAM/CRAM) and variants (VCF/BCF). It maps meaningful sample identifiers onto
storage locations, authorises each request, and returns tickets of pre-signed URLs covering
only the byte ranges required.

**Interfaces.**

| Direction | Counterpart            | Protocol                     | Purpose                                 |
|-----------|------------------------|------------------------------|-----------------------------------------|
| Inbound   | Researcher Environment | HTTPS via VPC Lattice        | htsget ticket requests                  |
| Outbound  | Data Releaser                   | S3 API                        | Read configuration for supporting dynamic sharing                      |
| Outbound  | Data Cache        | S3 API                       | Read indexes; pre-sign URLs with the node's own IAM principal |


## Bill and Log Processor

**Responsibility.** Processes native AWS bill and log artefacts and provides tools to construct CLI utilities that can
consume them in Parquet form.

**Interfaces.**

| Direction | Counterpart            | Protocol                     | Purpose                                 |
|-----------|------------------------|------------------------------|-----------------------------------------|
| Inbound  | Operator                   | S3 API (Parquet)                        | Optimised loading of parquet files into local memory for analysis                      |
