title: "🟰 2.9 Physical Security"
---


Source: [SATRE Specification v2.0](https://satre-specification.readthedocs.io/en/latest/)
| Pillar: Computing Technology and Information Security | Capability: 2.9


Stakeholders note that physical security is primarily relevant to on-premises compute; cloud providers handle this for cloud-hosted TREs. For genomics TREs that are predominantly cloud-based, this capability is less directly relevant — cloud provider certifications (SOC 2, ISO 27001) cover the physical layer.
