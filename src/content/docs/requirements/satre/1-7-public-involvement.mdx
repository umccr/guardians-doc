  <div class="satre-title">
    <span>🔶</span> 1.7.02 — Changed for Genomics
  </div>
  <p><strong>SATRE (Mandatory*):</strong> Details of TRE operations, data available and projects which have accessed the data must be publicly available.</p>
  <p class="satre-context mb-2">Standard transparency requirement for TREs with personal data.</p>
  <p><strong>Genomics context:</strong> Stakeholders raised whether there are instances in genomics where TRE projects need to be privately run — for example, pre-publication clinical research or commercially sensitive analyses. The default should be transparency, but there may be legitimate cases where project details (not data access records) are embargoed temporarily. The TRE should still maintain internal audit trails even where public disclosure is deferred.</p>
</div>
